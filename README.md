# ToDo List

## Descrição

O **ToDo List** é um projeto simples de uma lista de tarefas, desenvolvido com o objetivo de praticar as operações básicas de um CRUD (**Create, Read, Update e Delete**).

Este é um projeto voltado para iniciantes, servindo como um ambiente de estudo para conceitos fundamentais de desenvolvimento web utilizando Node.js, Express e MongoDB.

---

## Como executar o projeto

### Pré-requisitos

- Node.js instalado
- npm
- MongoDB em execução

### Passos

1. Clone este repositório.
2. Abra um terminal na pasta do projeto.
3. Instale as dependências:

```bash
npm install
```

4. Inicie a aplicação:

```bash
npm run dev
```
> **Observação:** Caso vá executar a aplicação em um ambiente Linux, altere o script "dev" de "set DEBUG..." para "export DEBUG".

---

## Configuração

As configurações da aplicação estão no arquivo:

```text
config/default.json
```

Nesse arquivo você pode alterar:

- Configuração da conexão com o banco de dados;
- Porta utilizada pelo banco de dados;
- Porta em que o servidor da aplicação será executado.

---

## Objetivo

Este projeto foi desenvolvido apenas para fins de aprendizado e prática, sendo indicado para quem está iniciando no desenvolvimento de aplicações com Node.js e deseja compreender o funcionamento de um CRUD completo.
